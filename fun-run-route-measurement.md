# Fun Run Route Measurement

Kwabena Osei's measurement of a possible 5k loop at Millrace Lane, walked with a measuring wheel on Saturday 11 April 2026.

- Loop: perimeter of the two full-size pitches and the mini pitches, then out along the riverside path and back. 1.66 km per lap; three laps is 4.98 km.
- Surfaces: grass for about 60%, compacted path for the rest. Muddy after rain on the bottom corner by the drainage ditch.
- No road crossings if the riverside path is used. The path is council land outside our lease, so we would need the council's permission.
- Pinch point: the gate between the field and the path is 1.2 m wide.

Why it matters: it shows a route exists without roads, which may avoid an athletics permit for an untimed run ([[northmere-athletics-club-licence-2026]]).
