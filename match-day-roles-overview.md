# Match Day Roles Overview

What a home Saturday at Millrace Lane needs from volunteers, in the order things happen. Useful for anyone new to the rota or covering a gap.

| Time | Role | People | Check needed |
|---|---|---|---|
| 08:00 | Pitch setup: goals, nets, corner flags | 2-3 | No |
| 08:15 | Gates and car park steward | 1-2 | No |
| 08:30 | Tea hut opens | 2 | No |
| 08:45 onwards | Changing-room door adults, per junior slot | 2 per slot | Yes |
| Each game | Linesperson (club assistant referee) | 2 | Yes for junior games |
| Each game | First-aider on duty | 1 per pitch block | Yes |
| 12:30 | Pitch take-down and kit return | 2-3 | No |
| 13:00 | Tea hut close, cash count | 1 + Helen | No |

## Notes

- On a typical home Saturday this is 25 to 35 slots, which is why one-off volunteers matter.
- The tea hut is run by [[helen-marsh]]; the kit by [[yusuf-demir]].
- Door adults follow [[run-the-saturday-changing-room-rota]].
- Anyone who sees something that worries them about a child tells the welfare officer the same day ([[report-a-welfare-concern]]), not the group chat.
