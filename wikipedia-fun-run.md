# Fun run

## Summary

Describes a fun run: a friendly road or cross-country race run for enjoyment rather than competition, often to raise money for a cause, sometimes with costumes and age categories, or as a side event to a bigger race.

## Why It Matters

Read after Sheila's [[masters-group-running-interest-list]] came in. It frames the choice in [[should-we-run-a-community-fun-run]]: a fundraising fun run once a year, with entry fees and sponsorship, against a regular free run. The fundraising model is the one that would help the [[match-funding-appeal]].

## Caveats
